Algoritmo SRT (Shortest Remaining Time - Apropiativo)

SRT es la variante expulsiva/desalojable de SJF. Evalúa su lógica de preemption y el impacto en la ejecución:

Condición de Desalojo (Preemption)
Ocurre cuando un proceso ingresa a la lista de listos con un tiempo de ráfaga remanente estrictamente inferior al remanente del proceso actualmente en CPU.
Desalojo por Cuota de Tiempo
Ocurre cuando el temporizador de hardware interrumpe el ciclo de ejecución porque el proceso consumió su quantum de 2 ticks.
Desalojo por Prioridad Fija
Ocurre únicamente si el proceso arribado tiene un valor de prioridad estática superior asignado por el administrador.
📖 Dónde estudiar este tema en la bibliografía
• Diapositivas Cátedra (Ing. Vázquez): Clase 4, Diapositiva 11 (SRT: menor tiempo restante a continuación, Apropiativo).
• Silberschatz (7ma Ed.): Cap. 5.3.2 (Versión con desalojo de SJF, pp. 161–162).
• Carretero: Cap. 3.4.3 (Primero el de menor tiempo restante, pp. 96–98).

Planificación en Sistemas Multiprocesador y Afinidad de CPU

En las arquitecturas multinúcleo modernas, el planificador enfrenta nuevos desafíos de coordinación y contención de recursos (Diapositiva 17 de teoría):

Contención de Recursos
Múltiples núcleos de procesamiento compiten simultáneamente por recursos de hardware compartidos como el bus de sistema, cachés L3 compartidas e interfaces de memoria principal.
Colisión Mecánica de Discos
Los brazos de lectura del almacenamiento magnético chocan mecánicamente al recibir órdenes paralelas de distintos procesadores.
📖 Dónde estudiar este tema en la bibliografía
• Diapositivas Cátedra (Ing. Vázquez): Clase 4, Diapositiva 17 (Planificación en Multiprocesadores: Contención, Alojamiento de tareas, Políticas combinadas).
• Silberschatz (7ma Ed.): Cap. 5.5 (Planificación de multiprocesadores: Afinidad, balanceo de carga, pp. 167–170).

    python autograder_tp3.py respuestas_tp3.json
  6. Entrega (Push): Realiza commit y push hacia GitHub: 
    git add respuestas_tp3.json
git commit -m "Entrega TP3 - [Tu Nombre]"
git push origin main
  7. Calificación Automática: GitHub Actions evaluará tu entrega en segundos emitiendo una insignia verde ✅ Check o roja ❌ con tu nota y reporte en la pestaña Actions.
